# 台指期價格監控系統

自動監控台指期價格變化，支援**上漲**和**下跌**雙向通知，透過 Telegram 發送即時警報。

## 📋 功能特色

- **即時價格監控**：每 3 秒抓取台指期最新成交價
- **雙向監控**：同時監控價格上漲和下跌
- **智能開盤重置**：日盤08:45、夜盤15:00自動重置基準點
- **階梯式通知**：漲/跌 500 點後開始通知，之後每 100 點通知一次
- **自動重置**：價格創新高/新低時自動重置通知記錄
- **週一自動重啟**：每週一 08:30 自動重置，清空週末資料
- **資料庫記錄**：所有訊號自動儲存到資料庫
- **Web 介面**：提供健康檢查、訊號記錄查詢等功能

## 🔧 系統架構

### 核心組件

1. **PriceRiseMonitor**：價格上漲監控器
   - **開盤重置**：日盤08:45、夜盤15:00自動重置基準點
   - **暖機機制**：收集 12 根 K 棒（1 小時）後開始監控
   - **低點追蹤**：從暖機期間的資料找出基準低點
   - **創新低重置**：價格創新低時自動重置通知記錄

2. **PriceDropMonitor**：價格下跌監控器
   - **暖機機制**：收集 36 根 K 棒（3 小時）後開始監控
   - **高點追蹤**：從暖機期間的歷史資料找出真正的高點
   - **創新高重置**：價格創新高時自動重置通知記錄
   - **週一重啟**：每週一 08:30 自動重置，重新暖機

3. **資料庫模型**
   - `SignalLog`：訊號記錄表
   - `Parameters`：參數設定表

4. **Flask Web 服務**
   - `/`：服務狀態
   - `/health`：健康檢查
   - `/heartbeat`：心跳監控
   - `/signals`：訊號記錄查詢
   - `/stats`：統計資料

## ⚙️ 可調整參數

### 上漲監控參數（PriceRiseMonitor）

```python
self.warmup_bars = 12           # 暖機期 K 棒數（12 根 = 1 小時）
self.min_alert_rise = 500       # 最少漲多少點才開始通知
self.alert_interval = 100       # 每漲多少點通知一次
```

### 下跌監控參數（PriceDropMonitor）

```python
self.warmup_bars = 36           # 暖機期 K 棒數（36 根 = 3 小時）
self.min_alert_drop = 500       # 最少跌多少點才開始通知
self.alert_interval = 100       # 每跌多少點通知一次
```

### 暖機時間建議

**上漲監控**：
- `12 根`（1 小時）：**推薦**，配合開盤重置機制，快速準確

**下跌監控**：
- `12 根`（1 小時）：快速啟動，但可能錯過真正高點
- `36 根`（3 小時）：**推薦**，平衡準確度與等待時間
- `60 根`（5 小時）：最安全，但需等待較久

在 `PriceRiseMonitor` 中：

## 📝 技術細節

### 資料處理流程

1. 每 3 秒抓取最新價格
2. 將 tick 資料重採樣為 5 分鐘 K 棒
3. **開盤重置**：日盤08:45、夜盤15:00自動重置基準點
4. **暖機階段**：收集足夠 K 棒資料
5. **暖機完成**：從歷史資料中找出基準點
6. **監控階段**：比較當前價格與基準點，判斷是否需要通知
7. 記錄訊號到資料庫

### 開盤重置機制

```python
# 檢查是否為開盤時間
is_day_open = (current_hour == 8 and 45 <= current_minute <= 50)
is_night_open = (current_hour == 15 and 0 <= current_minute <= 5)

# 開盤時重置基準點為當前價格
if (is_day_open or is_night_open) and self.session_start_price is None:
    self.session_start_price = current_price
    self.recent_low = current_price
    self.recent_low_time = current_time
    self.is_warmed_up = True
```

### 暖機機制

```python
if not self.is_warmed_up:
    if len(df_5min) < self.warmup_bars:
        # 繼續收集資料
        return None, None
    
    # 暖機完成，從歷史資料找基準點
    warmup_data = df_5min.tail(self.warmup_bars)
    self.recent_low = warmup_data['low'].min()  # 上漲監控找低點
    self.recent_high = warmup_data['high'].max()  # 下跌監控找高點
    self.is_warmed_up = True
```

### 防重複通知機制

使用 `notified_levels` 集合記錄已通知的級距：

notified_levels = {500, 600, 700}  # 已通知過的級距

## 🛡️ 容錯機制

- **資料庫備援**：連線失敗時自動使用本地 SQLite
- **參數備份**：儲存失敗時備份到本地 JSON 檔案
- **價格抓取**：失敗時自動重試，不中斷監控
- **暖機保護**：資料不足時不會發送錯誤通知
- **開盤重置**：確保每個交易時段都有正確的基準點
- **週一重啟**：清空週末資料，避免跨週計算錯誤
- **Keep-alive**：每 5 分鐘自動喚醒，防止服務休眠
