# 台指期價格下跌監控系統

自動監控台指期價格變化，當價格從高點下跌達到設定門檻時，透過 Telegram 發送即時通知。

## 📋 功能特色

- **即時價格監控**：每 3 秒抓取台指期最新成交價
- **智能暖機機制**：啟動後收集 3 小時資料，從歷史資料中找出真正的高點
- **階梯式通知**：跌 500 點後開始通知，之後每跌 100 點通知一次
- **自動重置**：價格創新高時自動重置通知記錄
- **日盤自動重啟**：每日 08:30 自動重置，確保完整監控日盤行情
- **資料庫記錄**：所有訊號自動儲存到資料庫
- **Web 介面**：提供健康檢查、訊號記錄查詢等功能

## 🎯 監控策略：方案 A（3 小時暖機）

```

18:30  進度：6/36 根 K 棒（還需 150 分鐘）

21:00  ✅ 暖機完成！從 18:00-21:00 找到歷史高點
  ↓ 開始監控
```

```

  ↓
20,100 → ✅ 創新高，重置記錄
  ↓
19,600 → 🔔 通知「跌 500 點」（重新計算）
```

### 日盤自動重啟
```
每日 08:30  🌅 自動重置
  ↓ 清空歷史資料
  ↓ 重新開始 3 小時暖機
11:30  ✅ 暖機完成（包含完整開盤資料）
  ↓ 開始監控日盤
```

## 🔧 系統架構

### 核心組件

1. **PriceDropMonitor**：價格下跌監控器
   - **暖機機制**：收集 36 根 K 棒（3 小時）後開始監控
   - **高點追蹤**：從暖機期間的歷史資料找出真正的高點
   - **創新高重置**：價格創新高時自動重置通知記錄
   - **日盤重啟**：每日 08:30 自動重置，重新暖機

2. **資料庫模型**
   - `SignalLog`：訊號記錄表
   - `Parameters`：參數設定表

3. **Flask Web 服務**
   - `/`：服務狀態
   - `/health`：健康檢查
   - `/heartbeat`：心跳監控
   - `/signals`：訊號記錄查詢
   - `/stats`：統計資料

## ⚙️ 可調整參數

在 `PriceDropMonitor` 類別中：

```python
self.warmup_bars = 36        # 暖機期 K 棒數（36 根 = 3 小時）
self.min_alert_drop = 500    # 最少跌多少點才開始通知
self.alert_interval = 100    # 每跌多少點通知一次
```

### 暖機時間建議

- `12 根`（1 小時）：快速啟動，但可能錯過真正高點
- `36 根`（3 小時）：**推薦**，平衡準確度與等待時間
- `60 根`（5 小時）：最安全，但需等待較久

### 日盤重啟時間

在 `main()` 函數中：

```python
# 每天 08:30-08:35 之間自動重置
if (current_hour == 8 and 30 <= current_minute < 35):
```

## 📝 技術細節

### 資料處理流程

1. 每 3 秒抓取最新價格
2. 將 tick 資料重採樣為 5 分鐘 K 棒
3. **暖機階段**：收集 36 根 K 棒（3 小時）
4. **暖機完成**：從歷史資料中找出最高點
5. **監控階段**：比較當前價格與高點，判斷是否需要通知
6. 記錄訊號到資料庫

### 暖機機制

```python
if not self.is_warmed_up:
    if len(df_5min) < self.warmup_bars:
        # 繼續收集資料
        return None, None
    
    # 暖機完成，從歷史資料找高點
    warmup_data = df_5min.tail(self.warmup_bars)
    self.recent_high = warmup_data['high'].max()
    self.is_warmed_up = True
```

### 防重複通知機制

使用 `notified_levels` 集合記錄已通知的級距：

```python
notified_levels = {500, 600, 700}  # 已通知過的級距
```

只有當價格跌到新的級距時才會發送通知。

### 日盤自動重啟機制

```python
# 每天 08:30 檢查是否需要重置
if (current_date != last_reset_date and 
    current_hour == 8 and 
    30 <= current_minute < 35):
    
    # 重置監控器
    price_monitor.reset()
    df_tick = pd.DataFrame(columns=['Close'])
    last_reset_date = current_date
```

## 🛡️ 容錯機制

- **資料庫備援**：連線失敗時自動使用本地 SQLite
- **參數備份**：儲存失敗時備份到本地 JSON 檔案
- **價格抓取**：失敗時自動重試，不中斷監控
- **暖機保護**：資料不足時不會發送錯誤通知
- **日盤重啟**：確保每天都有完整的開盤資料
- **Keep-alive**：每 10 分鐘自動喚醒，防止服務休眠

- 創新高時會自動重置通知記錄
