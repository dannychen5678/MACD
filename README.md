# 台指期價格下跌監控系統

自動監控台指期價格變化，當價格從高點下跌達到設定門檻時，透過 Telegram 發送即時通知。

## 📋 功能特色

- **即時價格監控**：每 3 秒抓取台指期最新成交價
- **智能高點追蹤**：自動追蹤最近 60 分鐘的最高點
- **階梯式通知**：跌 500 點後開始通知，之後每跌 100 點通知一次
- **自動重置**：價格創新高時自動重置通知記錄
- **資料庫記錄**：所有訊號自動儲存到資料庫
- **Web 介面**：提供健康檢查、訊號記錄查詢等功能

## 🎯 通知規則

```
高點 20,000 (10:00)
  ↓
19,500 → 🔔 通知「跌 500 點」
  ↓
19,400 → 🔔 通知「跌 600 點」
  ↓
19,300 → 🔔 通知「跌 700 點」
  ↓
20,100 → ✅ 創新高，重置記錄
  ↓
19,600 → 🔔 通知「跌 500 點」（重新計算）
```

## 📱 通知訊息範例

```
⚠️ 價格下跌 500 點
⏰ 2025-11-24 10:30:15
📈 高點: 20,000 (09:45:30)
📉 現價: 19,500
💥 跌幅: 500.0 點
🎯 級距: 500 點
```

## 🔧 系統架構

### 核心組件

1. **PriceDropMonitor**：價格下跌監控器
   - 追蹤最近 60 分鐘高點
   - 計算跌幅並判斷是否需要通知
   - 自動重置機制

2. **資料庫模型**
   - `SignalLog`：訊號記錄表
   - `Parameters`：參數設定表

3. **Flask Web 服務**
   - `/`：服務狀態
   - `/health`：健康檢查
   - `/heartbeat`：心跳監控
   - `/signals`：訊號記錄查詢
   - `/stats`：統計資料

## ⚙️ 可調整參數

在 `PriceDropMonitor` 類別中：

```python
self.lookback_minutes = 60   # 追蹤最近幾分鐘的高點
self.min_alert_drop = 500    # 最少跌多少點才開始通知
self.alert_interval = 100    # 每跌多少點通知一次
```

## 📊 資料收集與分析

系統會自動記錄每次訊號，並追蹤：
- 10 分鐘後價格
- 30 分鐘後價格
- 1 小時後價格
- 訊號結果（成功/失敗/中性）

每 30 分鐘自動分析勝率並優化參數。

## 🕐 交易時段

- **日盤**：08:45 - 13:45
- **夜盤**：15:00 - 05:00

系統會自動切換交易時段。

## 📝 技術細節

### 資料處理流程

1. 每 3 秒抓取最新價格
2. 將 tick 資料重採樣為 5 分鐘 K 棒
3. 計算最近 60 分鐘（12 根 K 棒）的最高點
4. 比較當前價格與高點，判斷是否需要通知
5. 記錄訊號到資料庫

### 防重複通知機制

使用 `notified_levels` 集合記錄已通知的級距：

```python
notified_levels = {500, 600, 700}  # 已通知過的級距
```

只有當價格跌到新的級距時才會發送通知。

## 🛡️ 容錯機制

- 資料庫連線失敗時自動使用本地 SQLite
- 參數儲存失敗時備份到本地 JSON 檔案
- 價格抓取失敗時自動重試
- Keep-alive 機制防止服務休眠
